# v0.4 — Home page (crear / abrir / configuración)

## Objetivo
Crear la página de inicio con tres opciones: crear proyectos, abrir proyecto, y configuración abajo (API + tema por ahora).

## Alcance (concreto)
*   Navegación: `enum View { Home, Chat, Config }`, `enum Message { GoHome, GoChat(chat_id), GoConfig, CreateProjectSubmitted(String), OpenProjectPicked }`. `view()` conmuta por `self.view`.
*   Home layout Iced: `center(column![text("ARQHIA").size(42), text("Agente nativo Iced").size(16), Space(30), button("Crear proyecto").width(280), button("Abrir proyecto").width(280), button("Ir al chat →").width(280), Space(20), rule, button("Configuración").width(280)] .spacing(12) .align_x(Center))`. `Ir al chat →` entra al Chat sin crear nada.
*   Crear proyecto: modal inline `text_input(nombre) + text_input(ruta opcional, placeholder /home/user/...) + button(Crear)/button(Cancelar)` en Home, y formulario inline en la sección Proyectos del sidebar (`nombre + ruta opcional "~/ARQHIA/projects/... o escribe la dirección"`). Ambos usan `create_project_with_dir`: crea dir si no existe (`fs::create_dir_all`, default `~/ARQHIA/projects/{slug}`), `INSERT INTO projects`, navega al cuestionario inmediato (no al Chat).
*   Sin seeds: no se crea ningún chat "General" al entrar; la lista puede empezar vacía y el chat nace al enviar el primer mensaje (`pending_project`). Divisores del sidebar condicionales (solo si hay contenido arriba).
*   Abrir proyecto: `rfd::FileDialog::new().pick_folder()` (bloqueante en hilo aparte vía `Command::perform`), si elige carpeta la registra como proyecto (nombre = file_name, auto-sufijo si choca) y navega al Chat vacío con `pending_project`.
*   Config abajo: la misma pantalla v0.1+v0.2 (API keys por provider + `pick_list(Dark/Light)`), accesible desde Home y desde Chat (botón ⚙ en header). Botón `← Volver` regresa al origen (`config_from`: Chat o Home, no siempre a Home).
*   Header Chat añade `button("⌂ Home")` para volver.
