# v0.1 — Chat normal multi-provider (Iced 0.13, sin agente)

## Objetivo
Ventana Iced nativa con un chat funcional que conversa con cualquier API (OpenAI, Anthropic, OpenRouter). Solo: configuración API + conversación. Nada de agente, sidebar, ni workspace.

## Alcance (concreto)
*   Ventana Iced 0.13: `struct App { messages: Vec<ChatMsg>, input: String, config: AppConfig, view: View }`, `enum View { Chat, Config }`, `enum Message { InputChanged(String), SendPressed, StreamChunk(String), StreamDone, StreamError(String), OpenConfig, SaveConfig, ProviderPicked(Provider), ApiKeyChanged(String), BaseUrlChanged(String), ModelChanged(String), TestConnection }`.
*   Chat: `column![scrollable(columna mensajes), row![text_input("Escribe...", input), button("Enviar")]]`. Mensaje: `struct ChatMsg { role: Role, content: String }`, `enum Role { User, Assistant }`. Streaming vía `Subscription::run` que emite `StreamChunk`.
*   Config API: pantalla con `pick_list([OpenAI, Anthropic, OpenRouter], ...)`, `text_input(api_key, password)`, `text_input(base_url)`, `text_input(model)`, `button("Guardar")`, `button("Probar conexión")`. Struct `ProviderConfig { provider: Provider, api_key: String, base_url: String, model: String }`.
*   LLM nativo por provider (3 archivos separados, no genérico):
    *   `src/llm/openai.rs`: `POST {base_url}/v1/chat/completions`, header `Authorization: Bearer {key}`, body `{model, messages, stream:true}`, parse SSE `data: {...choices[0].delta.content...}`.
    *   `src/llm/anthropic.rs`: `POST https://api.anthropic.com/v1/messages`, headers `x-api-key, anthropic-version: 2023-06-01`, body `{model, max_tokens:1024, messages, stream:true}`, parse SSE `content_block_delta`.
    *   `src/llm/openrouter.rs`: `POST https://openrouter.ai/api/v1/chat/completions`, headers `Authorization: Bearer, HTTP-Referer, X-Title`, body OpenAI-compatible + parse SSE igual que OpenAI.
    *   `src/llm/mod.rs`: `trait Provider { async fn chat_stream(history: Vec<ChatMsg>, cfg: ProviderConfig, tx: mpsc::Sender<String>) }`.
*   Persistencia: `~/.config/arqhia/config.toml` (config) + SQLite `~/.local/share/arqhia/arqhia.db` tabla `messages(id INTEGER PK, role TEXT, content TEXT, created_at TEXT)`.

## Tareas técnicas
*   Archivos: `src/main.rs, src/config.rs, src/chat.rs, src/db.rs, src/llm/{mod.rs,openai.rs,anthropic.rs,openrouter.rs}`.

*   Iced `Subscription` corta stream → usar `tokio::sync::mpsc` + `Subscription::run` con id por mensaje.
