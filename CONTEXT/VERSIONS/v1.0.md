# v1.0 — STACK nube + pulido general (estable)

## Objetivo
Llevar el STACK a la nube y hacer pulido general. Release estable v1.0.

## Alcance (concreto)
*   Cliente nube en `src/stack/cloud.rs`:
    1.  `push(item_id)`: `POST {cloud_url}/stack/push {title, code, tags, lang, meta}` con header `Authorization: Bearer {token de Config→Cuenta}`. Retorna `remote_id`.
    2.  `pull(since: timestamp)`: `GET /stack/pull?since=` → merge a SQLite local (upsert por `remote_id`, sin duplicar).
    3.  `search_cloud(query, tags)`: `GET /stack/search?q=&tags=` → mismos `ScoredItem` pero remotos. Fallback: si `reqwest` falla/timeout 5s, usa `stack::search` local y marca `Nube ○ offline`.
    4.  Config: `cloud_url: String (default http://localhost:3000)`, `cloud_token: String` en Config→Nube, `button(Probar conexión)`.
*   Backend referencia (no bloqueante): `cloud/` stub Axum + Postgres + S3. Si no hay infra, mock local `~/.arqhia/cloud/{items.json}` que implementa los 3 endpoints vía file-lock. El .md debe indicar cuál se usó.
*   UI: indicador `text("Nube ● online" / "○ offline")` en panel STACK + `row[button(Push), button(Pull)]` por item + lista remota con `★ rating nube`.
*   Orquestador final: `plan()` consulta `search_cloud` primero, si offline usa local (log indica fuente).
*   Pulido general:
    1.  Fix bugs v0.7/v0.9 reportados (lista en `TEMP.md` raíz).
    2.  `cargo clippy -- -D warnings`, `cargo fmt --check`, `cargo test` todo verde.
    3.  `cargo build --release` binario Linux `<30MB` aprox, open <2s, stream TTFB <300ms.
    4.  Docs: `README.md` raíz ARQHIA_P, `CHANGELOG.md` v0.1→v1.0 desde `VERSIONS.md`, `VERSIONS.md` todo 🟢.
    5.  Dogfooding: crear 1 proyecto real solo con ARQHIA (ej. `todo-cli`) y exportarlo (copia `Proyecto/` fuera) que compile con `cargo run` externo.
*   Tag: `git tag v1.0.0` + release notes (manual).
