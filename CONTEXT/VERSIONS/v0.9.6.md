# v0.9.6 — Revisión, optimización, refactor, tests, icono e instalador Linux (puerta de v1.0)

## Objetivo
Puerta de calidad de v1.0: dejar el código higienizado, refactorizado y medido, con tests por rol/skill/MCP, **icono propio instalado**, e instalador Linux que coloca binario + carpetas + config. Sin esta versión verde no hay release.

## Alcance (concreto)

### A. Higiene con backup obligatorio
1. Antes de tocar `unwrap/expect` productivos: `git status + git log + git remote -v` → verificar rama `ARQHIA` limpia y push al día en GitHub.
2. **Si NO está subido → STOP**: crear backup `~/.local/share/arqhia/backups/arqhia-<fecha>.tar.gz` (`ARQHIA_P/src`, `CONTEXT/`, `arqhia.db`, `config.toml`) y pedir confirmación. Solo con "ya está subido" se procede.
3. Sustituir `unwrap/expect` fuera de `#[cfg(test)]` por `Result + friendly_error + Log`; `todo!/unimplemented!` → error claro. `cargo clippy --all-targets -- -D warnings` + `cargo fmt --check` verdes.

### B. Refactor (sin cambio de comportamiento)
* Dividir `handlers/` gigantes (`chat.rs`, `questionnaire.rs`) por dominio; `views/` puro sin DB/red. Regla documentada en `PROJECT.md §4`.
* Dedup pendiente: una sola fuente para ignores / `estimate_tokens` / `trunc` / `resync_msg_meta`.
* `AGENTS.md` + `POLICIES.md` con los 5 roles v0.9.1.

### C. Optimización (targets v1.0)
* Release `<30MB` (`strip` + `lto`/opt), arranque `<2s`, TTFB `<300ms`. Peso y tiempos medidos en `TEMP.md` de cierre.
* Contexto: colapso progresivo + caché lecturas + ventana historial con métrica tokens/turno en el Log; `models.dev` cacheado sin re-descarga.

### D. Tests personalizados
* Por rol v0.9.1 (orquestador/analista/planner Net+Read/worker/auditor CLEAN/ISSUES, ≥2 ciclos, rojo no commitea).
* Skills v0.9.2 (`UI-REVIEW/CODE-REVIEW/QA-REPORT` generados y leídos por `read_context_docs`).
* MCP v0.9.3 stub + matriz E2E v0.1→v0.9.5 en Linux limpio, 0 críticos. Target `cargo test` ~120+ OK (3 ignored E2E).

### E. Icono (obligatorio pre-release)
* `assets/icon.svg` (fuente) + exportados `icon-16/32/64/128/256.png` e `icon.ico/.icns` (estos últimos pueden generarse en v1.0/v1.2, pero el `.svg`+`.png` quedan aquí).

### F. Instalador Linux (movido desde v0.9 Track B)
* Un instalador (`.deb` vía `cargo-deb` o script; fallback `.tar.gz`): binario → `/usr/bin/arqhia`; crea `~/.config/arqhia/` (`config.toml` defaults sin pisar existente), `~/.local/share/arqhia/` (DB, `skills/`, `backups/`), `~/ARQHIA/projects/`; `.desktop` + icono. **Jamás borra** DB/config/workspaces (migración en `POLICIES.md` §7).
* CI mínimo (`.github/workflows/ci.yml` o script): `check + test + clippy -D warnings + fmt --check + build` verde como prerrequisito de empaquetar.
