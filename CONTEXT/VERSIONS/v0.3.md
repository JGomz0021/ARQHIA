# v0.3 — Agente simple (workspace + CRUD archivos + bash simple)

## Objetivo
Iniciar el agente como tal: asignar un workspace por proyecto, crear/editar/borrar archivos reales, y ejecuciones simples de consola. Un agente simple (1 agente, sin orquestador aún).

## Alcance (concreto)
*   Workspace: `struct Project { id, name, path: Option<PathBuf> }`. UI en sidebar al seleccionar proyecto: `text_input("Ruta workspace /home/...") + button("Asignar") + text(validación: existe/no existe)`. Guard `path.canonicalize()?.starts_with(allowed_root)` y `path.is_dir()`. Columna `projects.path TEXT` en SQLite.
*   Tools (6) en `src/agent/tools.rs`, todas con guard `target.canonicalize() starts_with workspace.canonicalize()`:
    1.  `read_file(path) -> String` (`tokio::fs::read_to_string`).
    2.  `write_file(path, content)` (crea dirs padre).
    3.  `edit_file(path, old, new)` (reemplazo exacto 1 vez, error si 0 o >1 matches).
    4.  `delete_file(path)` (`tokio::fs::remove_file`).
    5.  `list_dir(path)` (lista nombres + flag dir/file).
    6.  `bash(cmd: String)` allowlist inicial `["ls","cat","echo","pwd","cargo --version","rustc --version","cargo check","cargo build","cargo test","cargo run"]`, `cwd=workspace`, timeout 30s vía `tokio::time::timeout`, captura `stdout+stderr` truncado a 4000 chars.
*   Agente: `src/agent/mod.rs` loop `user_msg + system_prompt(workspace, file_list) → LLM con function-calling → tool_call → execute → append resultado → LLM hasta final_answer (máx 10 iteraciones; el tope evita loops infinitos y coste descontrolado, el turno termina antes si el modelo responde sin tools)`. Log con `🔧 [paso N/10]`. Schemas JSON compatibles OpenAI `tools:[{type:function, function:{name, parameters}}]` y Anthropic `tools:[{name, input_schema}]` (mapeo en cada `llm/*.rs`).
*   UI: Log inferior en chat `container(height 130).scrollable(logs: "🔧 write src/main.rs OK" / "❌ fuera de workspace")` ubicado **por debajo de la entrada del chat** (al fondo), últimas 8 líneas. `system_prompt` incluye lista de archivos del workspace (top 20).
*   Selector de modelo en la entrada: `pick_list(["OpenAI · {model}", ...])` solo con providers con API key; `Message::QuickSwitchModel(String)` cambia `config.active` y guarda `config.toml` al instante.
*   Render Markdown en respuestas IA: `iced::widget::markdown::{parse, view}` con `Settings::with_text_size(15)` y `Style::from_palette`; negrita/cursiva/headings/listas/código inline/bloques. Mensajes de usuario en texto plano. Links → `Message::LinkClicked(Url)` → `xdg-open`.
