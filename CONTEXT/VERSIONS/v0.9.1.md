# v0.9.1 — BETA agentes (Orquestador/Analista/Planner/Workers/Auditor + loop)

## Objetivo
Convertir el orquestador implícito (v0.6–v0.7.3) en 5 roles explícitos con contratos, prompts y permisos propios, y cerrar el loop con re-análisis: `Orquestador > Analista > Planner > Workers > Auditor > (CLEAN fin | ISSUES > Analista revisa > Workers > Auditor > loop)`.

## Alcance (concreto)

### Roles
* **Orquestador** (`app/orchestrator.rs::Driver` + `AGENTS_TEMPLATE`): recibe el objetivo, decide plan directo vs work, lanza fases, escribe checklist `☑/▶/☐` y cierra (commit solo en verde). Log `orquestador: fase X/N`.
* **Analista** (`agent::analyze_workspace` ampliado): 1 llamada sin tools → `CONTEXT/ANALYSIS.md` (Estado, Restricciones, Archivos que toca, Riesgos; ≤200 palabras). En cada ciclo de fix **re-analiza** `TEMP.md` antes de re-planificar (cambio vs v0.7.3). Fallback a `context_block` si falla.
* **Planner** (`agent::plan_tasks` con **Net+Read**): además del brief, puede `fetch_url` (allowlist `net_domains`, permiso Net) y leer `extra_paths` (permiso Read) para documentar APIs/versiones en el plan. Escribe `CONTEXT/PLAN.md` con 2–3 tareas disjuntas + criterios de aceptación. **Sin Write/Bash por construcción** (el body nunca declara tools).
* **Workers** (`worker_system + exec_calls`): únicos con Write/Bash/Install (instalar deps solo con permiso Install, timeout 30s). Un worker = una tarea, secuenciales en v0.9.1 (async base = v1.0 §F, sandboxes + merge = v1.1 Pro).
* **Auditor** (`agent::audit_workspace`): reseña LLM + `cargo check/test/clippy --all-targets` (timeout 600s) → `TEMP.md` con `VERDICT: CLEAN|ISSUES` + `VERIFY: OK|FAIL` + `git diff --stat`. CLEAN = reseña limpia **y** verify OK; si el LLM cae, manda la puerta de calidad.

### Flujo
```
Orquestador > Analista (ANALYSIS.md) > Planner (PLAN.md) > Workers > Auditor (TEMP.md)
  > CLEAN → fin + commit "ARQHIA: <resumen>" (+ push opcional)
  > ISSUES → Analista revisa TEMP → Workers fix → Auditor → loop
```
Tope `Limits.max_fix_cycles` (0 = ilimitado); `Detener`/presupuesto/parada temprana cortan **sin commit** (`git_turn_interrupted`).

## Criterio Done (estricto)
* Turno con fallo fuerza ≥2 ciclos y cierra verde; rojo no commitea; `Detener` corta sin commit.
* Planner con `planner_net=true` documenta una URL externa en el plan (stub en test); con `false` ni la pide.
* Worker pide `write` → ejecuta; Planner pide `write` → denegado por rol.
* `cargo test` + `cargo clippy --all-targets` verdes.

## Test de Funcionalidad
1. "crea a.txt y b.txt" → 2 tareas → auditor CLEAN → commit único.
2. Romper `a.txt` a propósito → ISSUES → re-análisis → fix → CLEAN en ciclo 2.
3. Planner con Net OFF + "usa docs de https://…" → pide permiso Net antes de salir.
4. `Detener` a mitad → sin commit, placeholder retirado.

## Riesgos
* Planner con red trae contenido gigante → tope 8KB por fetch + aviso en Log.
* Loop infinito con modelo terco → `max_fix_cycles` + parada temprana + presupuesto.
