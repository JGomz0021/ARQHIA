# v0.2 — Sidebar + temas + proyectos agrupadores

## Objetivo
Hacer el chat más funcional: left sidebar con múltiples chats, cambio de tema en Config, y sección de proyectos que solo agrupa chats (sin workspace en disco aún).

## Alcance (concreto)
*   Layout: `row![container(sidebar).width(260), vertical_rule(1), container(chat).width(Fill)]`. Sidebar: `column![button("+ Nuevo chat"), scrollable(lista chats), rule, text("Proyectos"), scrollable(lista proyectos), row![text_input(nombre proyecto), button("Crear")]]`.
*   Modelo: `struct Chat { id: i64, title: String, project_id: Option<i64> }`, `struct Project { id: i64, name: String }`, `enum Message { NewChat, SelectChat(i64), DeleteChat(i64), NewProject, ProjectNameChanged(String), AssignChatToProject(chat_id, project_id), ThemePicked(ThemeMode), ... }`.
*   Chats: título = primeros 30 chars del primer mensaje. Click selecciona y carga sus `messages`. `x` borra con confirmación inline. `+ Nuevo chat` crea vacío y lo selecciona.
*   Proyectos: solo agrupadores lógicos. Crear proyecto = `INSERT INTO projects(name)`. Asignar = `pick_list` o `button("Mover a >")` por chat. Filtrado visual: chats bajo cada proyecto (árbol de 1 nivel, sin archivos).
*   Tema: `enum ThemeMode { Dark, Light }` en `AppConfig`, `pick_list([Dark, Light])` en Config, `Application::theme()` retorna `Theme::Dark/Light`. Cambio aplica en vivo sin reinicio. Persistido en `config.toml`.

## Paso a paso
1.  Crear `src/sidebar.rs`: `fn view_sidebar(chats, projects, selected) -> Element<Message>` con los widgets exactos de arriba, ancho fijo 260, `scrollable` para listas largas.
2.  Modificar `src/main.rs`: `struct App { chats: Vec<Chat>, active_chat: i64, projects: Vec<Project>, ... }`, `view()` = `row![sidebar, chat]`, `update()` maneja `NewChat/SelectChat/DeleteChat/NewProject/AssignChatToProject`.
3.  Modificar `src/db.rs`: nuevas tablas `chats(id PK, title TEXT, project_id INTEGER NULL, created_at TEXT)`, `projects(id PK, name TEXT, created_at TEXT)`, migrar `messages` añadiendo `chat_id INTEGER`. Funciones `create_chat()`, `rename_chat()`, `move_chat()`, `create_project()`.
4.  Modificar `src/config.rs`: añadir `theme: ThemeMode`, `set_theme()`, persistencia toml. `main.rs::theme()` lee `self.config.theme`.
5.  Añadir pantalla Config sección `Tema: pick_list + texto "Se aplica al instante"`.
6.  Verificar con 10 chats + 3 proyectos el scroll no rompe layout (min height, `Fill`).

## Tareas técnicas

*   Crear 3 chats, borrar 1, el activo cambia correctamente y el historial de cada uno es independiente.

*   Cambiar Dark→Light aplica en vivo y persiste tras reinicio.
*   Sin workspace en disco: proyectos no crean carpetas (verificable con `ls`).
