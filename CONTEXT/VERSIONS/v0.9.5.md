# v0.9.5 — Calidad estructural (desacoplar App + git async + docs)

> Nace de la auditoría integral 2026-09-14 (TOP 6–9). Prepara la puerta v0.9.6:
> deja el código testeable y documentado sin cambiar comportamiento.

## Objetivo
Deshacer el god-object `App`, sacar `git` bloqueante de la UI, cerrar la
deuda de `STACK`/uso y dejar docs + observabilidad mínima para el instalador.

## Alcance (concreto)

### A. Desacople `App` (sin cambio de comportamiento)
1. Nuevo `ChatHistory { messages, md, msg_usage }` con `push/clear/truncate`
   atómicos (adiós pushes/clears desalineados de `finish_agent_answer`).
2. Mover loop `auditor → analista → fix` de `handlers/agent.rs` a
   `orchestrator.rs` (`run_fix_cycle` puro + testeable); el handler solo
   despacha `Message`.
3. Split: `handlers/chat.rs` → `chat_stream.rs` + `chat_history.rs`;
   `views/config_view.rs` → `config_api.rs` + `config_git.rs` (+ resto).
   `dispatch_routes_every_group` sigue verde.

### B. Git async + STACK/uso
1. `git.rs::run/status_short/diff_stat/commit_all` → `tokio::process` o
   `Task::perform` (la UI no se congela; `push` ya era async).
2. `stack::save` ya en tx (v0.9.4); aquí: `record_tool_call_cat` en tx +
   `usage_stats.project` migra a `project_id` (con vista compat por nombre).
3. `workspace::code_outlines/scan_import` a `spawn_blocking` (no bloqueaWorkers async ya viven en v1.0; aquí solo no bloquear la UI).

### C. Docs + observabilidad mínima
1. `README.md` útil: qué es + quickstart (`cargo run`, LM Studio, key),
   rutas (`config.toml`, `arqhia.db`), `cargo test`, links a `CONTEXT/`.
2. Nuevos `docs/ARCHITECTURE.md` (regla de capas §3), `docs/CONFIG.md`
   (rutas + TOML ejemplo), `docs/SECURITY.md` (threat-model desktop:
   symlinks, `build.rs`, SSRF, prompt-injection), ADRs
   (Iced vs Tauri, rusqlite vs sqlx, rama única, secuencial→async v1.0).
3. `TEMP.md` rotativo (solo último auditor; historia a `HECHO.md`);
   `PROJECT.md §3` lista solo archivos reales (futuros a `ROADMAP`).
4. `tracing` mínimo (`eprintln!` → `tracing::info/warn`) + `tokio` slim
   (`full` → `rt-multi-thread, macros, fs, process, time, sync`).
