# v0.5 — Cuestionario simple → ESPEC.md

## Objetivo
Crear el cuestionario simple: serie de preguntas definidas que llenan un `.md` de especificaciones preconfiguradas (`CONTEXT/ESPEC.md`).

## Alcance (concreto)
*   Trigger doble: (a) automático al crear proyecto nuevo (Crear o Abrir con ruta nueva → `View::Questionnaire` con nombre prellenado); (b) manual desde Chat con proyecto activo, `button("Cuestionario")` → `View::Questionnaire { step: usize, answers: Answers }`. Al Finalizar/Cancelar vuelve a Chat.
*   Estructura: `struct Answers { nombre: String, descripcion: String, ubicacion: String, objetivo: String, publico: Publico, interfaz: Interfaz }`, `enum Publico { DevIndie, PequenoEquipo, Empresa, Estudiantes, Otro }`, `enum Interfaz { Nativa, Web, Cli, Movil, Backend }`.
*   Pasos (6, wizard con Atrás/Siguiente):
    1.  Nombre (texto 1 línea, `text_input`, validación no vacío, max 60).
    2.  Descripción (texto multilíneo `text_input` 3 líneas, min 10 chars).
    3.  Ubicación en el equipo (texto path, default = workspace actual, validación `Path::new(s).is_absolute()` o vacío=workspace).
    4.  Objetivo (texto multilíneo, min 10 chars).
    5.  Público objetivo (`pick_list([DevIndie, Pequeño-equipo, Empresa, Estudiantes, Otro])`).
    6.  Interfaz (`pick_list([Nativa, Web, CLI, Móvil, Backend])` + texto ayuda "ej. nativa=Iced/Tauri, web=...").
*   Salida: `src/questionnaire.rs::generate_spec(answers) -> String` con plantilla `minijinja`:
    ```md
    # {nombre}
    ## Descripción
    {descripcion}
    ## Ubicación
    {ubicacion}
    ## Objetivo
    {objetivo}
    ## Público objetivo
    {publico}
    ## Interfaz
    {interfaz}
    _Generado por ARQHIA v0.5_
    ```
    Guardado en `{workspace}/CONTEXT/ESPEC.md` (crea `CONTEXT/` si no existe). `Message::FinishQuestionnaire` escribe archivo y vuelve a Chat con `text("ESPEC.md generado")`.
*   Barra progreso: `text("Paso X/6") + progress_bar(0.0-1.0)`.
